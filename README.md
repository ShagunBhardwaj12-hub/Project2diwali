🪔 Happy Diwali – Interactive Greetings & Celebration Web App 🎆

An interactive and visually engaging web application created to celebrate the festival of lights! This project brings the festive spirit to life with animated Diyas, personalized Diwali wishes, and colorful fireworks.

✨ Features :- 

- 🪔 Interactive Diya Lighting: Click to light Diyas dynamically and watch the celebration grow with an interactive counter.
- 📜 Surprise Diwali Wishes: Reveal heartfelt Diwali greetings and festive blessings.
- 🎆 Animated Fireworks: Enjoy a colorful fireworks celebration powered by JavaScript animations.
- ✨ Festive UI: Beautiful golden theme, glowing effects, and smooth transitions.
- 📱 Responsive Design: Designed to provide a pleasant experience across different screen sizes.

🛠️ Tech Stack :- 

- HTML5 – Website structure and content.
- CSS3 – Styling, animations, glowing effects, Flexbox and Grid.
- JavaScript (ES6) – DOM manipulation, event handling, interactive counters, and animations.
